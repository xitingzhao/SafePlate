# SafePlate
Ein Lernspiel, das Grundschülern verschiedene Einschränkungen unterschiedlicher Ernährungsweisen näherbringt und auf Allergene sensibilisiert. 

Projektstruktur
Wir benutzen eine einfache Ordnerstruktur im Projekt, damit wir besser zusammen arvbeien können.
SafePlate/ 
├── project.godot 
├── scenes/ 
├── scripts/ 
├── assets/ 
└── data/

Kurze Erklärung:
- scenes/
  Hier sind alle Szenen vom Spiel, z.B. Hauptmenü, Spiel oder Auswahlseite.
- scripts/
  Hier sind alle Script Dateien für die Logik vom Spiel.
- assets/
  Hier kommen Bilder, Icons und andere Medien rein.
- data/
  Hier speichern wir Daten, z.B. Produkte als JSON Datei.
